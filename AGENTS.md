# Project context

Repo: **corisco-android-app**, part of the `corisco-wallet` GitHub org.
React Native (Expo SDK 57, managed workflow) wallet app for a self-custodial
Lightning wallet built on Spark (`@buildonspark/spark-sdk`). It pairs with the
ESP32 hardware signer (`corisco-firmware`) over BLE and **never holds private
key material** -- only public keys and signature shares.

## Layout

- `App.tsx` -- app root, connect/claim flow (see its top doc comment).
- `src/ble-hardware-signer.ts` -- `BleHardwareSigner`, implements the SDK's `SparkSigner` by asking the device over BLE; includes `withSpendContext` / `withoutSpendConfirmation`. No local-key fallback.
- `src/ble-transport.ts`, `src/ble-uuids.ts`, `src/postcard.ts` -- BLE connection and **hand-written mirrors** of the firmware's `corisco-protocol`.
- `src/screens/`, `src/components/` -- UI. `src/*-store.ts`, `settings`, `network.ts`, `price.ts`, `theme.ts` -- state/config.
- `tests/contract.test.ts` -- checks `postcard.ts` and UUIDs against the pinned firmware release's `vectors.json`.
- `android/` is generated by `npx expo prebuild --platform android`; don't hand-edit it.

## Commands

```bash
npm ci
npx tsc --noEmit        # CI typechecks every PR
npm run fetch-vectors   # needs `gh auth login`
npm test                # vitest contract tests
npx expo run:android    # needs JDK 17, Android SDK, a physical device (no BLE in emulator)
```

## Rules

- Protocol: postcard encodes enum variants by declaration order. New firmware variants are appended in the same relative position in `postcard.ts`. The firmware release is pinned in `package.json` under `corisco.firmware` (`tag`, `protocol`); to adopt a new one, bump it, fetch vectors, fix until tests pass.
- Network defaults to regtest; mainnet only via `EXPO_PUBLIC_SPARK_NETWORK=MAINNET`.
- The spend-confirmation wrappers in `ble-hardware-signer.ts` get extra scrutiny; claiming transfers must stay wrapped in `withoutSpendConfirmation`, spends must not.
- Releases via release-please from Conventional Commits. Never add `Co-Authored-By` or "Generated with Claude Code" lines to commits or PRs.
